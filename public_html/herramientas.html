Test de Velocidad

Recomendaciones a tener en cuenta antes de realizar el test:

1. Para tener un resultado confiable asegúrese de que ningún otro dispositivo esté usando el Internet en ese momento.

2. Preferiblemente realice el test desde un computador usando un cable ethernet o en caso contrario intente estar lo mas cerca posible del router para que la señal de recepción sea optima.

3. Puede que el test incluido en esta página no esté optimizado para su dispositivo, le recomendamos que descargue la aplicación que corresponde (Android, iOS, Mac, Windows) para sacar el máximo provecho.
